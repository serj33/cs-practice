Рабочая папка — файлы проекта, которые находятся на компьютере и с которыми я сейчас работаю.

Индекс — область Git, куда добавляются изменения, подготовленные для коммита.

Коммит — сохранённый набор изменений в истории репозитория.

Git — программа для контроля версий, которая работает с репозиторием и его историей на компьютере.

GitHub — онлайн-сервис для хранения Git-репозиториев и совместной работы с ними.

git diff — показывает изменения в рабочей папке, которые ещё не добавлены в индекс.

git diff --staged — показывает изменения, уже добавленные в индекс и подготовленные к коммиту.
